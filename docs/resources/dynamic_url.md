# cloudns_dynamic_url (Resource)

A dynamic URL for an A or AAAA record managed by ClouDNS. The generated URL authorizes dynamic DNS updates without additional authentication. Treat it as a credential and do not expose it in logs, outputs, or source control.

Use this resource with an existing A or AAAA record. Creating or reading it
retrieves the current Dynamic DNS URL, generating one if necessary. Changing
`domain` or `recordid` replaces the resource. Destroying it disables Dynamic DNS
for the record without deleting the DNS record. Import is not supported.

## Sensitive URL and Terraform state

Anyone with the URL can update the DNS record without additional authentication.
The `url` attribute is sensitive, so Terraform redacts it in standard plan and
apply output. Outputs referencing it must also set `sensitive = true`.
This does **not** remove the URL from Terraform state or saved plan files, and
does not encrypt it. Protect those files and restrict access to the state backend.
Commands such as `terraform output -raw dynamic_url` or `terraform output -json`
can reveal sensitive values. Do not publish the URL in logs or source control.

## Example Usage

Configure the ClouDNS provider using your usual environment-based authentication
and set `domain` to an existing zone in your account. The example creates an A
record with a documentation-only IP address and enables Dynamic DNS for it.
Use an AAAA record and an appropriate IPv6 address for IPv6 updates.

```terraform
variable "domain" {
  description = "An existing ClouDNS zone in your account."
  type        = string
}

resource "cloudns_dns_record" "home" {
  zone  = var.domain
  name  = "home"
  type  = "A"
  value = "192.0.2.1"
  ttl   = "60"

  # Let Dynamic DNS update the address without Terraform resetting it.
  lifecycle {
    ignore_changes = [value]
  }
}

output "dynamic_url" {
  value     = cloudns_dynamic_url.home.url
  sensitive = true
}

resource "cloudns_dynamic_url" "home" {
  domain   = cloudns_dns_record.home.zone
  recordid = cloudns_dns_record.home.id
}
```

### Required
